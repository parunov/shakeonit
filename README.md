# ShareBudget — Telegram-бот общих расходов

Бот ведет несколько независимых сборов в одной Telegram-группе, делит затраты между выбранными участниками, записывает возвраты долгов и в любой момент показывает точные балансы «кто кому сколько должен».

## Возможности

- несколько сборов в одной группе и фиксированная валюта каждого: BYN, RUB, EUR, USD;
- единый раздел «Сборы»: активные сборы текущей группы и все сборы пользователя;
- вступление только по кнопке «Участвовать в сборе»;
- групповая кнопка «Участвовать в сборе»: Telegram ID регистрируется одним нажатием без личного чата;
- затраты с выбором участников и точным распределением до копейки;
- возвраты долга между двумя участниками;
- текущие балансы и упрощенный список необходимых переводов;
- отдельная история затрат и возвратов, отмененные записи сохраняются;
- редактирование суммы и комментария транзакции;
- права автора транзакции и расширенные права администратора;
- передача роли администратора, удаление неиспользованных участников, выход из сбора;
- архивирование и восстановление в течение 30 дней;
- платежные реквизиты участника;
- обучение, помощь и быстрая запись затраты командой с включенным Privacy Mode.

## Быстрый запуск

Нужен Python 3.11 или новее.

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Оставьте Privacy Mode включенным. Бот получает Telegram ID пользователя непосредственно при нажатии кнопки «Участвовать в сборе».
3. Установите проект и зависимости:

   ```powershell
   py -3.11 -m venv .venv
   .venv\Scripts\Activate.ps1
   pip install -e ".[dev]"
   ```

4. Скопируйте `.env.example` в `.env` и замените `BOT_TOKEN`.
5. Запустите:

   ```powershell
   sharebudget
   ```

   Альтернатива: `python -m sharebudget.main`.

SQLite-база автоматически создается в `data/sharebudget.db`. Для резервной копии при остановленном боте достаточно скопировать этот файл.

## Запуск на VPS через systemd и webhook

В production бот принимает обновления через защищенный Telegram webhook. Для варианта без домена используется официальный self-signed режим с IP-адресом в SAN сертификата, портом `8443` и секретным заголовком webhook. Для локальной разработки без `WEBHOOK_URL` автоматически остается long polling.

Проект должен находиться в `/opt/shakeonit`. На Debian или Ubuntu выполните:

```bash
cd /opt/shakeonit
sudo bash deploy/install.sh
sudoedit /opt/shakeonit/.env
```

В `.env` замените только тестовое значение `BOT_TOKEN` на токен, полученный у BotFather. Файл исключен из Git и устанавливается с правами `0640`, поэтому токен не попадет в GitHub.

После сохранения токена запустите сервис:

```bash
sudo bash deploy/configure-webhook.sh 153.76.201.10 8443
sudo systemctl status shakeonit --no-pager
sudo journalctl -u shakeonit -n 100 --no-pager
```

Сервис запускается от отдельного системного пользователя `shakeonit`, автоматически стартует после перезагрузки VPS и перезапускается при временной ошибке.

Чтобы подсказка появлялась сразу после ввода `@ShakeOnIt_bot`, включите inline mode через `@BotFather`: `/setinline` → `@ShakeOnIt_bot` → задайте placeholder, например `Подсказка по общим расходам`.

## Telegram Mini App

Mini App — основной интерфейс ShakeOnIt и использует ту же базу и правила расчета, что и бот. Оно открывается с контекстом Telegram-группы или конкретного сбора. В приложении доступны сборы, балансы, затраты, возвраты, история, участники, приглашения, платежные данные, архив и административные действия. После значимых изменений бот отправляет в Telegram-группу один короткий отчет без звукового уведомления.

Авторизация выполняется через проверку подписи `Telegram.WebApp.initData`; отдельные логин и пароль не нужны. Сессии старше `WEBAPP_AUTH_MAX_AGE` отклоняются.

Production-настройка с доверенным HTTPS, nginx и автоматическим сертификатом:

```bash
cd /opt/shakeonit
sudo bash deploy/configure-miniapp.sh 153-76-201-10.sslip.io
```

После запуска бот сам устанавливает кнопку меню «Приложение». Чтобы ссылки `startapp` открывали Mini App непосредственно из группы, включите Main Mini App в `@BotFather` → Bot Settings → Configure Mini App и укажите тот же `WEBAPP_URL`.

После получения обновлений из GitHub установите актуальную версию проекта и перезапустите бота:

```bash
cd /opt/shakeonit
sudo /opt/shakeonit/.venv/bin/python -m pip install --editable /opt/shakeonit
sudo systemctl restart shakeonit
```

## Как пользоваться

Добавьте бота в группу и создайте сбор в Mini App или командой `/new`. Инициатор автоматически становится администратором и первым участником. Новый пользователь нажимает под сообщением сбора «Участвовать в сборе»: callback Telegram надежно передает его ID и сразу добавляет в сбор. Переход в личный чат, кнопка Start и определение ID по username не требуются; Privacy Mode остается включенным.

При затрате плательщик вводит сумму, отмечает кнопками всех, между кем она делится (включая себя при необходимости), и добавляет описание. Например, если Анна заплатила 90 EUR за троих, ее чистый баланс станет `+60 EUR`, а у двух друзей — по `−30 EUR`.

«Вернуть долг» означает уже совершенный перевод. Если Борис перевел Анне 30 EUR, его долг и сумма к получению Анны уменьшаются на 30 EUR.

Быстрый формат в группе при одном активном сборе:

```text
/expense@sharebudgetbot 40 @ivan @maxim билеты в цирк
```

Это обычная команда Telegram, поэтому она поступает боту при включенном Privacy Mode. `@ivan` и `@maxim` используются только для сопоставления с Telegram ID, ранее сохраненными после нажатия «Участвовать в сборе». Если у участника нет username, добавьте затрату через кнопочное меню — там пользователи выбираются по сохраненным Telegram ID.

## Проверки

```powershell
pytest
ruff check .
```

Тесты проверяют денежный парсинг, деление до копейки, расчет балансов, возвраты, отмену, редактирование и права доступа.

## Структура

- `src/sharebudget/db.py` — схема SQLite и подключение;
- `src/sharebudget/service.py` — бизнес-правила и расчет долгов;
- `src/sharebudget/handlers.py` — Telegram-сценарии;
- `src/sharebudget/keyboards.py` и `render.py` — интерфейс;
- `tests/` — автоматические тесты основной логики.
